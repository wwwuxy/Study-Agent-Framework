# Algorithm dependencies

StudyAgent uses [pyBKT](https://github.com/CAHLR/pyBKT) and
[py-fsrs](https://github.com/open-spaced-repetition/py-fsrs), both under the MIT license.
Their source distributions retain their upstream copyright and license notices.

pyBKT reference: Badrinath, A., Wang, F., Pardos, Z. A. (2021).
*pyBKT: An Accessible Python Library of Bayesian Knowledge Tracing Models*, EDM, 468–474.

The application adapts evidence, labels and question aggregation; it does not claim
those policies or the default parameters have been validated for a particular learner.
