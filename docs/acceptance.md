## 上传后自动更新数据库增量（2026-10-16）

- 上传成功即提交文件元数据、哈希与持久任务；默认 worker 自动领取任务，并将资料状态及时更新为 indexing。
- 远端理解完成后，章节、概念、来源、可选向量与更新后的学习计划在同一事务中发布。新概念保持 unknown，历史答题证据保留，不因上传直接变为已掌握。
- 网页观察资料／任务状态变化后，自动刷新资料详情与工作区的知识地图、学习状态及计划，无需刷新页面、手动 SQL 或 `job run`。
- 新增集成测试验证：已掌握旧课程后上传新概念，持久计划与实时推荐一致；启动真实 lifespan worker 后只调用上传接口即可自动入库，重复上传不重复建任务，重启后数据仍可读取。
- PostgreSQL 特定并发回归使用与真实答题入口相同的用户行锁，验证入库期间提交的答题证据不会被旧状态覆盖。
- SQLite 回归：90 项通过，1 项 PostgreSQL 专用测试跳过；真实 PostgreSQL：91 项通过。前端原有 5 项回归和生产构建通过。
- 浏览器通过文件选择器上传框架自有 PDF，仅使用显式演示适配器；未调用 task/run，未刷新页面，章节自动显示、知识地图由 3 个概念更新为 4 个，新增概念仍为待诊断。截图见 [自动更新知识地图](assets/auto-upload-database.png)。

自动后台更新要求保持默认 `MATERIAL_WORKER_ENABLED=true`。主动关闭 worker 的管理员仍须使用手动任务命令。此增量无需新增数据库迁移，沿用 M2 的 0002。
