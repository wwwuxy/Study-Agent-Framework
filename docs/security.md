# M1 / M2 安全与隐私

- **凭证**：API Key 通过 Fernet 在后端加密；列表、错误响应和 OpenAPI 示例不返回原文；浏览器不使用 localStorage / sessionStorage 保存凭证。更换加密主密钥需要迁移密文，不能直接覆盖环境变量。
- **账号**：scrypt 密码摘要；随机会话令牌只在 HttpOnly / SameSite=Strict Cookie 内，数据库保存摘要。HTTPS 部署必须打开 Secure。登出撤销当前会话。
- **隔离**：所有对象查询先校验用户和空间归属；外部用户请求统一 404。模型配置和空间使用所有者复合外键，题目 / 概念 / 事件也限制空间归属。
- **SSRF**：默认 HTTPS，仅公网 IP；DNS 解析限时，拒绝任一非公网结果。每次请求重新校验，连接固定到校验过的 IP，保留原 Host 和 TLS SNI / 证书验证；禁用重定向和环境代理。URL 不允许 userinfo、query、fragment。管理员可显式放开内网供自托管使用。
- **跨站**：写请求检查 Origin；仅允许当前请求源或配置的前端源。生产反向代理必须清理来自不可信客户端的转发头。JSON API 不开启跨源 Cookie 权限。
- **低信任输入**：目标、答案与教材只作为模型数据，不作为服务器命令；前端依靠 React 转义文本，不执行模型 HTML。所有模型输出严格校验，不使用模型生成 SQL / Python / shell。
- **网络调用**：可配置 5–60 秒请求超时，最多三次默认尝试，总任务 90 秒。认证失败立即停止，超时、限流、服务不可用有明确错误。取消协程可传播到 HTTP 请求；关闭页面不保证服务端请求自动终止，任务仍受总时限约束。
- **调用授权**：只有用户发起连接测试、创建课程、课堂、提示和开放评分时才请求远端服务。UI 在模型连接时说明发送数据和费用；M2 每次上传/重索引单独授权文件与可选向量，后台仅执行已授权的资料任务。
- **日志**：记录请求 ID、路由模板、状态码、耗时；不记录 Cookie、Authorization、请求体或模型原始错误文本。AgentRun 保存模型和用量；金额缺失时明确为 unavailable。
- **部署边界**：应用内限流适合单实例 MVP；多副本生产需共享限流设施或网关。无管理员后台、密码找回、账号导出 / 删除或运维级审计系统；这些不是当前 M1 完成声明的一部分。
- **数据备份**：数据库和加密主密钥分开保管；`.env` / `data` 不提交版本控制；本机启动只绑定 loopback，Compose 不公开数据库端口。

M2 开放实际探测通过的 PDF。文件按用户/空间 UUID 路径存储，文件权限 0600；原名不参与磁盘路径。上传检查大小、MIME、头尾标识和主动内容字节特征，这不是完整杀毒。原文仅作为鉴权附件下载，不执行内容；不引入正文解析/OCR 依赖。

删除立即清理本地原文、章节与向量并停止新检索，旧课堂动态过滤来源；远端清理由持久任务跟踪，迟到上传句柄也会登记。清理失败继续显示保留警告和可重试任务，凭证被待清理句柄引用时禁止删除。直接修改原凭证可能使旧句柄无法自动清理，须到服务商控制台核对。远端保留、备份和账单仍遵循第三方政策。

资料摘要与检查点属于私有数据库内容，不能写入日志；意外任务异常日志只记录类型和任务 ID，不回显模型数据。教材内容不视为系统指令，输出要经过 Schema 与引用校验。所有文件/向量/删除请求复用固定 DNS IP、Host、TLS SNI 和禁止重定向的 SSRF 保护。
