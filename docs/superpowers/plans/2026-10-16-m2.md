## 全局约束

- 不解析 PDF 正文、不解包 EPUB/DOCX，不引入 OCR/本地向量模型。
- 首个原生文件适配器采用 Files + Responses 协议，当前只验证 PDF；兼容聊天端点继续明确拒绝文件。
- 文件探测使用框架生成的一页随机标识 PDF，实际上传、理解并校验标识；失败仅关闭对应能力，不猜测支持。
- Embedding 仅当用户配置远端模型、检测成功且本次上传授权时启用；默认关键词 + LLM 选证据。向量保存在 JSON；提供可选 PostgreSQL pgvector 镜像存储/检索，不依赖本地模型。
- 上传逐次授权；原文和索引按用户/空间隔离。删除即刻停止检索，并保留可恢复的远端清理状态。
- 页码默认不可信；没有原生可验证定位的适配器不展示可靠页码。
- 所有索引结果经严格 Schema 校验后原子发布；只更新知识来源，不自动增加掌握度。

## 检查重点

- 探测/上传失败或凭证轮换不能认证另一配置；处理中修改模型必须拒绝旧任务继续。
- 任务租约与代次校验，删除/取消期间不能重新发布索引或继续额外调用。
- 删除后旧课堂/题目只保留历史作答，动态屏蔽已删资料的引用详情。
- 索引支持原子替换；重试不重复增加概念/章节，不读取其他用户数据。
- 没有真实 Key 不声称实际云端验收成功；用传输替身验证协议，记录付费验证未执行。
