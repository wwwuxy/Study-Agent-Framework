# StudyAgent M1 Implementation Plan

**Goal:** 实现规格第八节阶段一：目标 → 诊断 → 教学 → 测验 → 持久化状态 → 下一动作。
**Architecture:** FastAPI + SQLAlchemy + Alembic，PostgreSQL 为部署数据库，SQLite 为本地快速启动与测试数据库。React/Vite Web UI，所有模型请求经过 ProviderAdapter。
**Spec:** `StudyAgent_Framework_Development_Spec.md`，特别是 0.2、8 阶段一、10.1。
**Execution:** 在当前空项目直接编码，按用户文档 10.1 执行；不创建额外工作树或提交，不重复请求设计批准。

## Global Constraints

- 禁止本地 Embedding、教材正文提取或 OCR；仅实现阶段一。
- 凭证加密保存、输出和日志脱敏；服务端验证用户及空间归属。
- 模型不能修改掌握度；学习事件只追加、去重，状态规则可重放。
- 所有结构化模型输出严格校验，失败事务不保留半成品。
- 网络请求限时、有限重试；默认拒绝非公网模型地址及重定向。

## Review Focus

- 同一题换事件 ID 重答不能被算成第二个独立掌握情境。
- 并发重复事件和重复初始化需要数据库唯一约束或锁保证。
- 假模型仅在显式启用 demo 时可用，不冒充真实模型能力。
- 提示事件必须保存在服务端，不能通过提交 assistance=none 绕过。
- 开放回答低置信评分保留证据但不更新掌握状态。
