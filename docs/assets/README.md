更新素材时，应从更新后的代码重新构建并启动独立演示实例，按实际操作采集画面，保留演示标识和内容来源说明。不要录入真实 API Key、账号凭证、教材或试卷；更改画面后需逐帧确认步骤文字与界面一致。
