# 开发路线图

- **M1**：本次实现目标、BYOK 聊天接入、初始诊断、课堂、测评、事件、规则状态和下一动作。验收证据见 acceptance.md。
- **M2**：已加入原生 PDF 能力探测、私有存储、远端分步理解、持久任务、出处、检索与删除、CLI/Web。远端 Embedding 和 pgvector 可选；真实 BYOK 教材与 pgvector 部署验收待执行，详情见 m2-materials.md 与 acceptance.md。
- **M3**：已实现完整 pyBKT＋py-fsrs、Q-Matrix、到期复习、教学模式、7／30 天学习报告、版本化评测与参数维护。按用户确认，所有空间强制双算法、删除旧规则回退。原生训练与优化已用自有合成数据验证，真实教育效果仍待评估。
- **M4**：已实现持久周期调度、每日任务、偏离建议、站内消息、自然周报与目标预测、手动AI分析配额、执行面板及独立登录／注册和账号隔离。按用户要求取消新提醒设置、授权与数据控制模块；后台不调用LLM。见 [M4指南](m4-active-learning.md)。

阶段四工程验证与遗留边界见 acceptance.md；阶段二只开放已探测的 PDF，演示文件适配器始终标注固定样例。
